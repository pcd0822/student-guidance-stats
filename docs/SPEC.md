# 업무 규칙 요약 (작업 지시서 정리본)

원래 작업 지시서에는 실명이 들어 있어 git 에 넣지 않았습니다. 이 문서는 그 지시서를 실명 없이 줄이고, 그 뒤 대화에서 확정된 내용을 더한 것입니다. 코드와 이 문서가 다르면 코드와 테스트가 기준입니다.

## 0. 목표

구글 스프레드시트와 Apps Script(`reference/Code.gs`)로 하던 「출결 통계 / 생활지도 및 학생선도」 업무를 로컬 데스크톱 앱으로 옮깁니다. Code.gs 가 하던 일은 모두 하면서 아래 네 가지를 더했습니다.

1. **제외 처리를 학생 × 월 단위로**
2. **나이스 원본 파일을 정제 없이 그대로 올리고, 분석할 학년을 체크**
3. **학생선도 소위원회 회의록(hwpx)을 양식 그대로 생성하고 미리보기**
4. **첫 실행 때 생활규정 마법사**: 회차별 지도 방안은 학년별로 입력합니다

모든 데이터는 그 컴퓨터 안(`data/app.db`)에만 둡니다.

## 1. 데이터

- **학번**: 5자리 문자열입니다. 학년×10000 + 반×100 + 번호이고, 앞을 0으로 채웁니다.
- **월 순서**: 학년도 순서를 씁니다(3,4,…,12,1,2). 비교식은 `(m - 시작월 + 12) % 12` 이고, 시작 월은 설정값(기본 3)입니다.
- **다시 올리기**: (학년도, 학년, 월) 자료를 다시 올리면 덮어씁니다.
- **누적**: 저장하지 않고, 월별 기록에서 매번 계산합니다.
- **테이블**
  - `settings`, `monthly_records`(미인정 결석·지각·조퇴·결과 + 원본 한 줄), `uploads`
  - `exclusions`: 달별 사유·방식·서류 횟수를 JSON 으로 둡니다.
  - `exclusion_alerts`, `guidance`(차수·실시 월·날짜·방안), `meetings`
  - `students`: 학적 상태·변동일·위기관리·비고

## 2. 나이스 「결석자 조회」 파일 읽기

### 파일 구조

- 머리 행은 페이지마다 반복됩니다.
- 페이지마다 쪽 번호 행이 있고, 마지막에 `합 계` 행이 있습니다.
- 학년·반 칸은 값이 바뀌는 첫 줄과 각 페이지 첫 줄에만 적혀 있습니다.

### 열 위치 (0부터)

| 열 | 번호 | 내용 |
|---|---|---|
| A | 0 | 학년 |
| C | 2 | 반 |
| D | 3 | 번호 |
| E | 4 | 성명 |
| G~J | 6~9 | 결석 |
| K~N | 10~13 | 지각 |
| O~R | 14~17 | 조퇴 |
| S~V | 18~21 | 결과 |

- 지각·조퇴·결과 칸도 결석과 같은 순서입니다: 질병·미인정·기타·인정.
- 따라서 **미인정은 7·11·15·19열**입니다.

### 읽는 규칙

- **학생 행 판정**: D 가 숫자이고, E 가 숫자가 아닌 비어 있지 않은 문자열인 행만 학생으로 봅니다.
  - 이 규칙 하나로 반복 머리행, 쪽 번호 행, 합계 행이 모두 걸러집니다.
- **학년·반**: A·C 가 숫자면 새 값으로 갱신하고, 빈칸이면 위의 값을 이어 씁니다.
- **기간과 월**: 3행 D·I 열에 있는 기간에서 월을 찾습니다. 1·2월이면 학년도는 연도 − 1 입니다.
- **확장자**: .xls 가 실제로는 HTML 표인 경우가 있습니다. lxml 로 읽고, rowspan·colspan 을 채워 펼칩니다.
- **올리는 방식**: 한 번에 여러 파일을 올릴 수 있고, 한 파일에는 한 달 자료만 들어 있어야 합니다.
  - 기간이 여러 달에 걸친 파일은 거절합니다. 학생별 합계만 있어 달별로 나눌 수 없기 때문입니다.
- **확인 기준**: 원본 파일에서 3학년만 읽은 결과가 사람이 정제한 파일과 같아야 합니다. 인원·학번·이름·미인정 4종이 모두 일치해야 합니다(`tests/test_parse.py`).

## 3. 생활규정 엔진 (기본값, 마법사에서 바꿀 수 있음)

1. **세는 대상**: 미인정 결석·지각·조퇴·결과만 셉니다. 질병·기타·인정 출결은 세지 않습니다.
2. **환산 규칙**: 점수 = 결석 합계 + ⌊(지각+조퇴+결과 합계) ÷ 3⌋ 입니다.
   - **기간 전체를 먼저 더한 뒤 한 번에 나눕니다.** 나머지는 다음 달로 이월되고, 화면에 「이월 n회」로 보입니다.
   - 예: 9월 결석 1·지각 2 → 1점. 10월 지각 1·조퇴 3 → 1 + ⌊6/3⌋ = 3점.
3. **집계 기간**: 사용자가 체크한 달들입니다.
4. **누적 초기화**: 생활지도를 받으면 마지막으로 지도받은 달까지의 기록을 빼고, 그다음 달부터 다시 셉니다. 이월도 함께 사라집니다.
5. **대상자 기준**: 초기화 뒤 누적이 3점 이상이면 대상자입니다.
6. **차수**: 지도 횟수가 0·1·2회면 학년부 생활지도 1·2·3차, 3회 이상이면 학생선도위원회입니다.
7. **조회표와 명단**: 조회표에는 원자료를 그대로 보이고, 제외·초기화는 대상자 명단에만 적용합니다.
8. **환산 방식 통일**: 명단 기준값과 화면 누적값은 같은 환산 방식을 씁니다. Code.gs 는 이 둘이 어긋났습니다.
9. **마법사 단계**:
   - 학교
   - 세는 대상
   - 환산(가중/단순, N)
   - 기준 점수
   - 초기화(지도한 달까지 / 지도한 달 전까지)
   - 단계 수
   - **학년별 × 차수별 지도 방안**
   - 회의록 기본값(장소·위원장·위원)

   규칙은 `settings.rules` JSON 하나에 두고, 계산 함수는 모두 이것만 읽습니다.

## 4. 월별 제외 처리

- **등록 단위**: 학생 한 줄에 달 칩이 있습니다. 달마다 사유와 방식을 고릅니다.
  - **그 달 전체 제외**: 자퇴·숙려제 등
  - **서류 확인 횟수만큼 제외**: 학원 수강 등. 항목별 횟수를 넣되, 기록 값을 넘을 수 없습니다.
- **달 칩**: 그 학생에게 미인정이 있는 달만 고를 수 있습니다.
- **추가 기능**: 「전체 기간」 토글, 한 달에 사유 여러 개, 여러 학생 한 번에 추가(학번 목록 붙여넣기)
- **계산**: 서류 방식은 기록에서 서류 횟수를 뺀 나머지를 누적합니다. 표에는 「조퇴 10 (서류 7)」처럼 보입니다.
- **「서류에 없는 내역」 알림** 세 가지:
  1. 기록이 서류보다 많을 때
  2. 제외 등록이 있는 학생에게 서류 없는 달의 미인정이 생겼을 때. 처음 등록한 달보다 뒤의 달에만 뜹니다.
  3. 그 때문에 대상자가 되었거나 차수가 바뀌었을 때. 맨 위에 「대상자 됨」으로 올립니다.

  알림마다 「서류 횟수 수정」(그 학생 칸으로 이동) / 「확인함」 버튼이 있습니다. 반별 엑셀로 내보낼 수 있습니다.

## 5. 학생 관리 (v1.0.4)

- **명단**: 올린 나이스 자료로 자동으로 만듭니다. 전입생 등은 직접 추가하거나 붙여넣기로 등록합니다(학번·이름·상태·변동일·위기(O)·비고).
- **학적 상태**: 재학·전출·자퇴·휴학·학업중단 숙려·위탁교육·기타
  - 떠나는 상태면 변동 달부터 학년도 끝까지 제외로 등록하는 것을 고를 수 있습니다.
- **위기관리학생**: 회의록에서 자동으로 「위기관리학생」 구분이 됩니다.
- **삭제**: 직접 추가했고 기록이 없는 학생만 지울 수 있습니다.

## 6-1. 미인정 현황 공유·내려받기 (v1.0.5)

- **내용**: 학년도 전체 원자료. 학생 한 명이 4행(결석·지각·조퇴·결과) × 자료가 있는 달 + 합계 + 제외 반영 환산.
  - 제외 처리된 달은 값을 지우지 않고 회색으로 칠합니다. 서류 방식은 「3 (서류 2)」, 합계는 「5 (제외 2)」.
  - 제외 반영 환산은 제외만 반영한 누적입니다. 생활지도 초기화는 반영하지 않습니다(대상자 판정은 대시보드 ③ 이 기준).
  - 미인정이 하나도 없는 학생은 넣지 않습니다. 학적이 재학이 아니면 이름 옆에 상태를 붙입니다.
- **다운로드(대시보드)**: 범위(학생 한 명 / 학급 / 전체·학년) + 달 칩 + 형식.
  - xlsx: 반마다 시트, A4 가로 맞춤, 머리행 반복 (`/api/report.xlsx`).
  - PDF: 화면에서 쪽을 그려 jsPDF 로 묶습니다. 반마다 새 쪽, 한 쪽에 학생 7명.
- **링크 공유**: 두 방식 중 고릅니다.
  1. 교내망 링크: `app/share.py` 가 0.0.0.0:8790(쓰이면 다음 번호)에 따로 서버를 엽니다. 주소는 `/s/<암호키>`, `/s/<암호키>/data`, `/s/<암호키>/report.xlsx` 셋뿐입니다. 키가 틀리거나 공유가 꺼져 있으면 404. 「새 주소 만들기」 로 키를 바꾸면 옛 주소는 바로 막힙니다. 설정은 `settings.share`(enabled·token·port)이고 앱을 다시 켜면 자동으로 다시 엽니다.
  2. 공유 파일: 같은 화면에 자료를 넣은 HTML 한 파일(`/api/share/file`). 만든 때의 사본입니다.
- **공유 화면(담임용)**: 보기(전체 학생 / 학급 / 학생 한 명) · 학년 · 반 · 학생 검색 · 달 필터 칩, 인쇄·PDF(브라우저 인쇄, 반마다 쪽), 교내망 링크에서는 엑셀과 새로 고침도 있습니다.

## 7. 회의록 (hwpx)

### 양식 구조

- **표1**: 일시, 장소, 참석자(위원장/위원), 심의 안건, 심의 내용
- 내용 칸에 들어가는 것:
  1. 회부 학생: 기준 문구 + 학번 이름 목록
  2. 위반 사항(○○○○. ○. ○○. 기준)과 **표2**
     - **표2 = 월별 미인정 내역**입니다. 학생 한 명이 열 하나를 차지하고, 표 하나에 3명까지 둡니다.
     - 달마다 「결석」, 「지각/조퇴/결과」 두 행이 있습니다.
     - 0 은 `-` 로 씁니다.
     - 마지막 「총합」 칸에는 직전 지도 이력과 판정 기간 누적을 적습니다.
  3. 지도 방안: 위기관리학생 문구와 **표3**(학번 | 이름 | 생활지도 내역)

### 채우는 규칙

- **회부 학생과 표2**: 선택한 학생 전원을 넣습니다. 위기관리학생도 포함합니다.
- **표3**: 「생활지도 실시」 학생만 넣습니다. 위기관리학생은 뺍니다.
- **표2의 달**: 마지막 지도 다음 달부터 기준 월까지, 미인정이 있는 달입니다.
- **총합 칸**: 대상자 판정에 쓴 것과 같은 기간·같은 값입니다. 학년도 전체 누적은 선택했을 때만 「참고:」 줄로 따로 적습니다.
- **확정**: 표3 학생에게 생활지도 이력이 기록되고, **기준 월까지** 누적이 초기화됩니다. 확정을 되돌릴 수도 있습니다.

### 만드는 방법

- `section0.xml` 을 복사해 고칩니다. `header.xml` 의 모양 ID 는 그대로 다시 씁니다.
- 고친 문단의 `linesegarray` 는 지웁니다.
- mimetype 은 zip 의 첫 항목에 무압축으로 넣습니다.
- 검사 테스트는 `tests/test_minutes.py` 입니다.

## 9. Code.gs 에서 고친 버그

1. 제외가 학생 전체에 걸리던 문제 → 월별 제외로 바꿨습니다.
2. 같은 달을 다시 올리면 누적이 두 번 더해지던 문제 → 덮어쓰고, 누적은 매번 계산합니다.
3. 월을 달력 순서로 비교하던 문제 → 학년도 순서로 비교합니다.
4. 반복 머리행의 「미인정」 글자를 대상자로 잡던 문제 → 학생 행 판정 규칙으로 걸러냅니다.
5. 월 시트 이름에 학년·학년도가 없던 문제 → (학년도, 학년, 월) 키를 씁니다.
6. 명단 기준값과 표시값의 환산이 다르던 문제 → 하나로 통일했습니다.
