생활지도·학생선도 통계 — 학교 컴퓨터 설치 안내

1. 이 압축 파일을 풉니다(마우스 오른쪽 → 압축 풀기).
2. install.bat 을 두 번 누릅니다.
   - 「Windows의 PC 보호」 창이 뜨면 「추가 정보」 → 「실행」을 누릅니다.
3. 처음에는 Python 과 필요한 프로그램을 내려받느라 몇 분 걸립니다(관리자 권한 필요 없음).
4. 끝나면 바탕 화면에 바로 가기 두 개가 생깁니다.
   - 「생활지도·학생선도 통계」: 앱 실행
   - 「생활지도 통계 업데이트」: 최신판으로 업데이트(입력한 자료는 그대로 남음)

설치 위치: C:\Users\<사용자>\GuidanceStats
학생 자료는 그 안의 data 폴더에만 저장되고 인터넷으로 나가지 않습니다.
앱을 쓰는 동안 검은 창을 닫지 마십시오(닫으면 앱도 꺼집니다).

자세한 안내: https://github.com/pcd0822/student-guidance-stats
